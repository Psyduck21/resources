01 Arrays ▼
Description

In the Java virtual machine, arrays are dynamically allocated objects stored in contiguous memory locations on the heap. The array size is determined fixedly at the moment of allocation and cannot be altered thereafter. This contiguous memory architecture ensures fast random indexing capabilities, mirroring the memory properties of C++ array segments.

Advantages
  • Constant-Time Indexing: Accessing any element using its bracket index requires only a single memory address lookup, completing in O(1) time.
  • Optimal Cache Locality: Sequential traversal is highly efficient because elements reside adjacent to each other, maximizing CPU cache utilization.
  • Jagged Array Construction: Multidimensional layouts can be allocated as jagged arrays, allowing each row to contain a different number of column slots.
Java Syntax
Java 
// 1D Array Declaration and Allocation  
int[] arr1 = new int[5];  
int[] arr2 = {1, 2, 3, 4, 5};  
  
// Jagged Multi-dimensional Array Allocation  
int[][] jaggedArray = new int[3][];  
jaggedArray[0] = new int[2];  
jaggedArray[1] = new int[4];  
jaggedArray[2] = new int[3];  
  
// Iteration using standard for-loop  
for (int i = 0; i < arr2.length; i++) {  
    int value = arr2[i];  
}  
  
// Traversal using enhanced for-each loop  
for (int element : arr2) {  
    int value = element;  
}

02 Strings ▼
Description

In Java, strings are represented by the immutable java.lang.String class. Immutability ensures thread safety and allows identical string literals to be cached in the JVM String Pool to save memory. However, modifying a string requires allocating a new object on the heap, which can cause performance overhead if done repeatedly in loops.

Java Syntax
Java 
// String allocation strategies  
String s1 = "literal_value";  
String s2 = new String("heap_value");  
  
// Iterative character parsing  
for (int i = 0; i < s1.length(); i++) {  
    char c = s1.charAt(i);  
}  
  
// Conversion to a character array  
for (char element : s1.toCharArray()) {  
    char curChar = element;  
}  
  
// Important Constructors  
String emptyStr = new String();  
char[] charSeq = {'j', 'a', 'v', 'a'};  
String fromArray = new String(charSeq);  
String cloneStr = new String(s1);

  • ⚠Index Out Of Bounds: Reading an out-of-bounds character via charAt() triggers StringIndexOutOfBoundsException.
03 StringBuilder ▼
Description

StringBuilder represents a mutable sequence of characters, functioning as an internal resizable character buffer. It is specifically designed to eliminate the performance bottleneck of string concatenation by avoiding unnecessary string object recreation. It is unsynchronized and fast, making it ideal for single-threaded applications.

Java Syntax
Java
// Default construction (pre-allocated 16 character slots)  
StringBuilder sb = new StringBuilder();  
  
// Modifying and appending elements  
sb.append("base_value");  
sb.append('_');  
sb.append(100);  
  
// Pre-allocate a custom starting capacity  
StringBuilder sbSized = new StringBuilder(100);  
  
// Converting back to an immutable String  
String result = sb.toString();

04 Classes ▼
Description

Java is a class-centric, object-oriented language; all variable declarations, operations, and execution blocks must reside inside class definitions. Classes serve as blueprints for objects, which are allocated on the heap and managed via references. Static class members belong to the class itself and are shared across all instances.

Java Syntax
Java
// Structuring class blueprints  
class Edge {  
    int target;  
    int weight;  
    static int edgeCount = 0; // Shared static variable  
  
    // Constructor  
    public Edge(int target, int weight) {  
        this.target = target;  
        this.weight = weight;  
        edgeCount++;  
    }  
  
    // Static Utility Method  
    public static int getEdgeCount() {  
        return edgeCount;  
    }  
}
Interview Usage
Node Representation Custom PriorityQueue Elements Dynamic Interval Modeling
Pitfalls
  • ⚠Default Equality and Hash Checks: Custom classes must override both equals() and hashCode() to work correctly inside HashMap or HashSet collections.
  • ⚠Non-Static Variable Access: Attempting to reference instance-level fields from inside static contexts results in a compilation failure.
05 Generics ▼
Description

Java Generics provide compile-time type safety by allowing classes, interfaces, and methods to be parameterized with different object types. Generics use type erasure — the compiler checks types at compile-time and then replaces them with raw java.lang.Object references in the generated bytecode.

Java Syntax
Java
// Generic Class declaration  
class QueueContainer<T> {  
    private T item;  
    public void add(T item) { this.item = item; }  
    public T get() { return item; }  
}  
  
// Generic Method declaration  
class SearchHelper {  
    public static <E> boolean includes(E[] array, E element) {  
        for (E item : array) {  
            if (item.equals(element)) return true;  
        }  
        return false;  
    }  
}  
  
// Diamond Operator Instantiation  
QueueContainer<Integer> q = new QueueContainer<>();
C++ Equivalents
C++ STLJavaNotes
template<typename T>class Container<T>C++ templates generate unique machine code copies per type; Java uses type erasure.
Pitfalls
  • ⚠Primitive Types Restriction: Generics only work with reference types. Use wrapper classes like Integer, Character instead of int, char.
  • ⚠Generic Array Instantiation: new T[] is prohibited due to type erasure. Use (T[]) new Object[size] instead.

Collections Framework

06 Collections Framework Hierarchy ▼
Description

The Java Collections Framework provides a unified architecture for modeling and manipulating groups of objects. Understanding its hierarchy of interfaces (Collection, List, Set, Queue) and concrete implementations (ArrayList, HashSet, ArrayDeque) is essential for writing efficient algorithms.

Java Syntax
Java
// Polymorphic declarations — program to interface  
List<Integer> arrayList = new ArrayList<>();  
Queue<String> arrayQueue = new ArrayDeque<>();  
Set<Double> hashSet = new HashSet<>();  
Map<Integer, String> hashMap = new HashMap<>();  
  
// Copy constructor pattern  
List<Integer> listCopy = new ArrayList<>(existingSet);
Pitfalls
  • ⚠Structural Modification Violations: Modifying a collection while iterating over it throws ConcurrentModificationException. Use the iterator's own remove() method.
  • ⚠Autoboxing Performance Overhead: Repeatedly inserting primitives triggers boxing operations, degrading performance in high-frequency loops.

List Implementations

07 ArrayList ▼
Description

ArrayList is a dynamic, resizable-array implementation of the List interface — the standard equivalent to C++'s std::vector. Provides fast O(1) index-based access, but requires O(n) element shifts during modifications at intermediate indices. Resizes by a factor of 1.5 when capacity is exceeded.

Java Syntax
Java
// Default Constructor (Initial Capacity of 10)  
ArrayList<Integer> list = new ArrayList<>();  
  
// Explicit Capacity Pre-allocation  
ArrayList<Integer> l2 = new ArrayList<>(100);  
  
// Appending elements  
list.add(10);  
list.add(20);  
  
// Traverse list  
for (int i = 0; i < list.size(); i++) {  
    int val = list.get(i);  
}  
  
// Backtracking pattern — remove last element  
list.remove(list.size() - 1);

09 Stack ▼
Description

The legacy java.util.Stack implements LIFO stack operations, but extends java.util.Vector which uses thread-safe synchronization locks — highly inefficient for competitive programming. Modern applications should use Deque (ArrayDeque) as a faster stack alternative.

Java Syntax
Java
// ❌ Legacy — avoid in competitive programming  
Stack<Integer> stack = new Stack<>();  
  
// ✅ Preferred — non-synchronized stack via Deque  
Deque<Integer> fastStack = new ArrayDeque<>();  
fastStack.push(10);  
fastStack.push(20);  
int top = fastStack.peek();   // view top  
int val = fastStack.pop();    // remove top  
boolean empty = fastStack.isEmpty();

10 Queue ▼
Description

In Java, Queue is an interface for FIFO collections. Implemented via ArrayDeque (circular array) or LinkedList (pointer-based), both supporting fast O(1) insertions and removals. Always prefer ArrayDeque-backed queues for performance.

Java Syntax
Java
// FIFO Queue — ArrayDeque backed  
Queue<Integer> queue = new ArrayDeque<>();  
queue.offer(10);  
queue.offer(20);  
  
// BFS-style processing loop  
while (!queue.isEmpty()) {  
    int val = queue.poll(); // removes and returns head  
}  
  
int head = queue.peek(); // view head without removing

11 Deque (ArrayDeque) ▼
Description

Deque supports constant-time insertions and removals at both ends. Implemented as a circular array via ArrayDeque, it outperforms both legacy Stack and pointer-based LinkedList for stack and queue operations. Uses a bitwise mask on a circular power-of-two array to wrap indices efficiently.

Java Syntax
Java
Deque<Integer> deque = new ArrayDeque<>();  
  
deque.addFirst(10);  // push to front  
deque.addLast(20);   // push to rear  
  
int first = deque.peekFirst();  // view front  
int last = deque.peekLast();    // view rear  
  
deque.pollFirst();   // evict front  
deque.pollLast();    // evict rear

§ 05

Heaps

12 PriorityQueue ▼
Description

PriorityQueue is an unbounded priority queue backed by a balanced binary min-heap. Guarantees O(log n) for insertions and removals, and O(1) to retrieve the minimum element. Default ordering is natural ascending order, but can be customized with a Comparator.

Java Syntax
Java
// Default min-heap (lowest value at top)  
PriorityQueue<Integer> minHeap = new PriorityQueue<>();  
  
// Max-heap (highest value at top)  
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(  
    Collections.reverseOrder()  
);  
  
// Custom object sorting (Dijkstra example)  
PriorityQueue<int[]> pq = new PriorityQueue<>(  
    (a, b) -> Integer.compare(a[0], b[0])  
);  
  
// With predefined capacity and comparator  
PriorityQueue<Integer> pq2 = new PriorityQueue<>(50, (a, b) -> b - a);  
  
pq.offer(val);  // insert  
pq.poll();      // remove top  
pq.peek();      // view top
Common Operations
MethodPurposeSyntaxComplexity
offerInsert element into heappq.offer(val)O(log n)
pollRetrieve and remove top elementpq.poll()O(log n)
peekRetrieve top without removingpq.peek()O(1)
sizeGet number of elementspq.size()O(1)
removeRemove a specific elementpq.remove(obj)O(n)
Interview Usage
Dijkstra's Shortest Path Top K Elements Interval Merging Kth Largest Element
C++ Equivalents
C++ STLJavaNotes
std::priority_queue<T>PriorityQueue<T>C++ defaults to a max-heap; Java's default PriorityQueue is a min-heap.
Pitfalls
  • ⚠Underflow Comparator Bugs: Using subtraction (a, b) → a - b can cause integer overflow. Always use Integer.compare(a, b).
  • ⚠Dynamic Object Updates: Modifying a field on an object already inside a heap does NOT trigger re-sort. Must remove, modify, re-insert.

16 HashMap ▼
Description

HashMap is a hash table-based implementation of Map. Averages O(1) for put, get, and containsKey. In Java 8+, buckets convert from linked list to Red-Black tree when their size reaches 8 and map capacity is at least 64 (treeification), protecting against worst-case O(n) collision attacks.

Java Syntax
Java
HashMap<String, Integer> map = new HashMap<>();  
  
// Standard put and frequency update pattern  
map.put("key", 1);  
map.put("key", map.getOrDefault("key", 0) + 1);  
  
// Check before insert  
map.putIfAbsent("key", 0);  
  
// Lazy initialization (computeIfAbsent)  
map.computeIfAbsent("key", k -> new ArrayList<>()).add(val);  
  
// Traversal using entrySet  
for (Map.Entry<String, Integer> entry : map.entrySet()) {  
    String k = entry.getKey();  
    int v = entry.getValue();  
}

Sorting Utilities

19 Comparator ▼
Description

Comparator is a functional interface for defining dynamic, custom sorting logic for collections and arrays. Allows sorting the same class in multiple ways, with sorting logic decoupled from the class definition itself.

Java Syntax
Java
// Lambda comparator: sort by age ascending  
Comparator<Student> ageCompare =  
    (s1, s2) -> Integer.compare(s1.age, s2.age);  
  
// Multi-field: sort by age, then name on tie  
Comparator<Student> multiCompare = (s1, s2) -> {  
    int ageDiff = Integer.compare(s1.age, s2.age);  
    return ageDiff != 0 ? ageDiff : s1.name.compareTo(s2.name);  
};  
  
// Invert ordering

    int n = nums.length;  
    int[] prefix = new int[n + 1];  
    for (int i = 0; i < n; i++) {  
        prefix[i + 1] = prefix[i] + nums[i];

Sliding Window (Monotonic Deque)
Java
public static int[] maxSlidingWindow(int[] nums, int k) {  
    int n = nums.length;  
    int[] result = new int[n - k + 1];  
    Deque<Integer> dq = new ArrayDeque<>(); // monotonic queue of indices  
  
    for (int i = 0; i < n; i++) {  
        // Evict indices that have fallen outside the window  
        if (!dq.isEmpty() && dq.peekFirst() < i - k + 1)  
            dq.pollFirst();  
  
        // Maintain decreasing monotonic order  
        while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i])  
            dq.pollLast();  
  
        dq.addLast(i);  
  
        // Record the window's maximum  
        if (i >= k - 1) result[i - k + 1] = nums[dq.peekFirst()];  
    }  
    return result;  
}
Monotonic Stack (Next Greater Element)
Java
public static int[] nextGreaterElement(int[] nums) {  
    int n = nums.length;  
    int[] result = new int[n];  
    Arrays.fill(result, -1);  
    Deque<Integer> stack = new ArrayDeque<>();  
  
    for (int i = 0; i < n; i++) {  
        // Pop elements smaller than the current value  
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i])  
            result[stack.pop()] = nums[i];  
        stack.push(i);  
    }  
    return result;  
}
BFS (Graph)
Java
public static List<Integer> traverseBFS(int start,  
        List<List<Integer>> adj, int vertices) {  
    List<Integer> order = new ArrayList<>();  
    boolean[] visited = new boolean[vertices];  
    Queue<Integer> queue = new ArrayDeque<>();  
    visited[start] = true;  
    queue.offer(start);  
  
    while (!queue.isEmpty()) {  
        int curr = queue.poll();  
        order.add(curr);  
        for (int neighbor : adj.get(curr)) {  
            if (!visited[neighbor]) {  
                visited[neighbor] = true;  
                queue.offer(neighbor);  
            }  
        }  
    }  
    return order;  
}
Dijkstra's Shortest Path
Java
static class Node implements Comparable<Node> {  
    int vertex, weight;  
    public Node(int v, int w) { vertex = v; weight = w; }  
    @Override  
    public int compareTo(Node o) { return Integer.compare(weight, o.weight); }  
}  
  
public static int[] dijkstra(int start,  
        List<List<Node>> adj, int vertices) {  
    int[] dist = new int[vertices];  
    Arrays.fill(dist, Integer.MAX_VALUE);  
    dist[start] = 0;  
  
    PriorityQueue<Node> pq = new PriorityQueue<>();  
    pq.offer(new Node(start, 0));  
  
    while (!pq.isEmpty()) {  
        Node curr = pq.poll();  
        int u = curr.vertex;  
        if (curr.weight > dist[u]) continue; // stale entry  
  
        for (Node edge : adj.get(u)) {  
            int v = edge.vertex, w = edge.weight;  
            if (dist[u] + w < dist[v]) {  
                dist[v] = dist[u] + w;  
                pq.offer(new Node(v, dist[v]));  
            }  
        }  
    }  
    return dist;  
}
Topological Sort — Kahn's Algorithm
Java
public static int[] kahnTopologicalSort(int n,  
        List<List<Integer>> adj) {  
    int[] inDegree = new int[n];  
    for (int i = 0; i < n; i++)  
        for (int nb : adj.get(i)) inDegree[nb]++;  
  
    Queue<Integer> q = new ArrayDeque<>();  
    for (int i = 0; i < n; i++)  
        if (inDegree[i] == 0) q.offer(i);  
  
    int[] order = new int[n];  
    int idx = 0;  
    while (!q.isEmpty()) {  
        int node = q.poll();  
        order[idx++] = node;  
        for (int nb : adj.get(node))  
            if (--inDegree[nb] == 0) q.offer(nb);  
    }  
    return idx == n ? order : new int[0]; // empty if cycle  
}
Union Find (Disjoint Set Union)
Java
class UnionFind {  
    private final int[] parent, rank;  
  
    public UnionFind(int size) {  
        parent = new int[size];  
        rank = new int[size];  
        for (int i = 0; i < size; i++) parent[i] = i;  
    }  
  
    // Path compression  
    public int find(int i) {  
        if (parent[i] != i) parent[i] = find(parent[i]);  
        return parent[i];  
    }  
  
    // Union by rank  
    public boolean union(int i, int j) {  
        int ri = find(i), rj = find(j);  
        if (ri == rj) return false;  
        if (rank[ri] > rank[rj]) parent[rj] = ri;  
        else if (rank[ri] < rank[rj]) parent[ri] = rj;  
        else { parent[rj] = ri; rank[ri]++; }  
        return true;  
    }  
}
